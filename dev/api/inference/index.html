Inference

Posterior

AshDieback.AshDiebackPosterior — Type
AshDiebackPosterior(prob::AshDiebackProblem, ranges = peoc_prior_ranges();
                    alg = SparseCrankNicolson())

The posterior of the model parameters under independent uniform priors on ranges (a 10 × 2 matrix of [lower upper] rows; equal bounds fix a parameter), as a LogDensityProblems.jl log density over the free parameters only.

Use free_parameters to see which parameters are free and full_parameters to turn a point of the posterior back into an AshDiebackParameters. The log density is -Inf outside the prior and where the likelihood is zero, and is evaluated with the diffusion algorithm alg.

source
AshDieback.peoc_prior_ranges — Function
peoc_prior_ranges()

The uniform prior ranges [lower upper] of the ten parameters shipped with PEOC 1.0 (1_or_2_parameters_of_the_AMIS_or_MH_algorithm.py), one row per parameter in the order of AshDiebackParameters. A row with lower == upper fixes that parameter (r_symp = 1000).

source
AshDieback.reduced_model_prior_ranges — Function
reduced_model_prior_ranges()

Prior ranges of the paper's reduced model (eq. 13), used for its AMIS results: no Allee effect and no rainfall effect (r_allee = beta_1 = 0), gamma = 21.50001, C_pers = 1 and r_symp = 1000 fixed; beta_0, D, S_sat, C_init and kappa free with the ranges of peoc_prior_ranges.

Metropolis–Hastings

AshDieback.ComponentwiseGammaMH — Type
ComponentwiseGammaMH(shape; blocked = false)
ComponentwiseGammaMH(post::AshDiebackPosterior; shape = peoc_mh_shapes(), blocked = false)

The Metropolis–Hastings sampler of PEOC, as an AbstractMCMC.AbstractSampler for any LogDensityProblems.jl log density over positive parameters (wrap it in AbstractMCMC.LogDensityModel, or pass an AshDiebackPosterior to sample).

Each iteration proposes θ′ⱼ ~ Gamma(shape = sⱼ, scale = θⱼ/sⱼ), a multiplicative random walk with mean θⱼ, for one parameter, cycling through the parameters in order (or for all of them at once with blocked = true), and accepts it with the Metropolis–Hastings probability, which corrects for the asymmetric proposal. A parameter at exactly 0 cannot move.

shape gives sⱼ for each free parameter; the second form takes the shapes of the free parameters of post from a 10-vector. sample needs initial_params.

source
AshDieback.peoc_mh_shapes — Function
peoc_mh_shapes()

The gamma proposal shapes of PEOC 1.0's Metropolis–Hastings (scale_para_MH), one per parameter in the order of AshDiebackParameters: 100 for r_symp and 200 for the others. A proposal from θⱼ has mean θⱼ and standard deviation θⱼ/√shape.

AMIS

AshDieback.amis — Function
amis([rng], target, mean, covariance; iterations, samples, threaded = Threads.nthreads() > 1)

Adaptive multiple importance sampling (Cornuet et al. 2012), as used by PEOC for the paper's posterior. target is a LogDensityProblems.jl log density, such as an AshDiebackPosterior; mean and covariance define the initial Gaussian proposal (covariance entries are variances, as PEOC's scale_para_AMIS on the diagonal).

Each iteration draws samples points from the current proposal N(mₖ, Σₖ) and evaluates the target there (in parallel threads if threaded). It then recomputes the deterministic-mixture weights of all draws so far, wᵢ ∝ π(θᵢ) / ((1/(k+1)) Σⱼ φ(θᵢ; mⱼ, Σⱼ)), and moves the proposal to their weighted mean and covariance. The mixture is evaluated on the log scale, so it is better conditioned than PEOC's; the algorithm is the same. Throws a DegenerateProposalError if the proposal covariance becomes singular.

source
AshDieback.AMISResult — Type
AMISResult

Output of amis.

Fields:

  • samples::Vector{Matrix{Float64}}: the draws of each iteration, one column per draw.
  • logdensity::Vector{Vector{Float64}}: the target log density at each draw (-Inf for draws outside the prior or with zero likelihood).
  • weights::Vector{Vector{Float64}}: the final normalised importance weights of every draw, with the same layout as logdensity.
  • means::Vector{Vector{Float64}}, covariances::Vector{Matrix{Float64}}: the proposal of each iteration, and the one the last iteration produced.
source
AshDieback.DegenerateProposalError — Type
DegenerateProposalError(iteration, message)

The Gaussian proposal of amis became degenerate at iteration: the weights collapsed onto fewer samples than there are free parameters, so the weighted covariance is singular. Use more samples per iteration, or fix more parameters.

Turing

AshDieback.turing_model — Function
turing_model(post::AshDiebackPosterior)

The posterior post as a Turing.jl model, with a uniform prior on each free parameter (in one vector θ, ordered as free_parameters) and the model's log-likelihood added with @addlogprob!. Requires using Turing.

The likelihood has no useful gradient (it is a 4556-cell PDE solve per year, with kinks), so use a gradient-free sampler, e.g. sample(turing_model(post), MH(), 1000), or pass a ComponentwiseGammaMH through externalsampler.
